# Fixture packages

Real `tsumugi.context-package/1` documents, hand-written and committed as
files. They are what makes the reader testable with no sibling installed, which
is the whole point of reading a contract rather than importing a library
(ADR-0007).

`tests/test_contract_conformance.py` validates every one of them against
`tests/contracts/context-package-1.json` — a copy of the schema `tsumugi`
publishes, vendored here so that a fixture cannot quietly stop conforming to
the contract it claims. A fixture that drifts fails the build rather than
silently testing akashi against a document nobody would ever send it.

The `anchor.start` and `anchor.end` offsets are consistent with the item text
lengths, which the reader checks and which is what makes the reported offsets
worth anything. If you edit an item's `text`, fix its `end`.

| File | What it is for |
|---|---|
| `gear-ja.json` | Japanese, three items, one of them an interpretation, two omissions under different rules |
| `contract-en.json` | English legal prose: a section reference, a duration, a sum of money |
| `protected-ja.json` | Non-null `provenance.protection`, reversible. ADR-0008's path |

None of these is generated by `tsumugi` itself. The seam test that builds one
with the reference producer is v0.5, and it is what will catch this reader
drifting from the contract it re-implements — a hand-written fixture and a
hand-written reader can agree with each other and both be wrong.
